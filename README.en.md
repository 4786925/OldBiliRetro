## Features

- **Login**: QR-code login / cookie login / manual cookie import / cookie export
- **Home**: personalized recommendations when logged in; trending by default; anime & movie sections
- **Search**: videos, anime, movies, live rooms, users; direct AV/BV jump; 20-item history with one-tap clear; scroll position preserved on paging
- **Video detail**: multi-part selection, collections, related videos, uploader entry, long-press to copy the description
- **Player (self-compiled IJKPlayer)**:
  - **Fixed landscape** orientation
  - Quality list reflects what the server actually provides (360P / 720P / 1080P / 1080P60 / 2K)
  - Stream format selectable: **DASH** (all qualities, default) / **MP4** (single stream, most stable)
  - Gestures: brightness / volume / seek / double-tap pause; **long-press for 2× speed**
  - Speed menu: 0.75x / 1.0x / 1.25x / 1.5x / 2.0x
  - Danmaku settings adjustable **during playback**, synced with the settings page
  - Top bar: back + title + like / coin / share / follow; bottom: progress bar on top, then play/pause, danmaku toggle, danmaku settings, send danmaku, with speed and quality on the right
- **Danmaku**: full DanmakuFlameMaster (stroke, shadow, collision detection, bitmap cache)
- **Comments**: view / reply / nested replies / like / post; image + text comments
- **User space**: videos / dynamics / profile of any uploader; follow status detection
- **Dynamics / Messages / Favorites / Anime following**
- **Download**: per-part download, resume support, quality selection
- **Settings**: incognito mode, **no-image mode**, **clear cache**, stream format, default quality, **compatibility list**, EULA, device info, crash log export; logout also clears message/dynamic/favorite caches

## Compatibility

### System & ABI

| ABI | Min API | Android | Native player | HTTPS |
|---|---|---|---|---|
| armeabi (ARMv5) | **9** | 2.3 ~ 2.3.7 | self-built | ✅ |
| armeabi-v7a | **9** | 2.3 ~ 4.4 | self-built | ✅ |
| arm64-v8a | 21 | 5.0 ~ 17 | self-built | ✅ |
| x86 | **9** | 2.3 ~ 7.x | self-built | ✅ |
| x86_64 | 21 | 5.0+ | self-built | ✅ |

- `minSdkVersion 6` (Android 2.0.1); **the lowest fully usable version is Android 2.3**
- `targetSdkVersion 26`; installs and runs up to Android 16 / 17
- An in-app **compatibility list** is included (shown before accepting the EULA on first launch, and in Settings)

### Video quality

| Quality | Availability | Notes |
|---|---|---|
| 360P | all devices | single stream |
| 480P | ❌ removed | bilibili no longer serves profile 32; requests fall back to 360P |
| 720P | all devices | single stream |
| 1080P | most videos | single stream; may require login / premium |
| 1080P 60fps | some videos | requires DASH; hidden on Android 2.x |
| 2K | few videos | requires DASH + premium; hidden on Android 2.x |

> The quality list is dynamic: it reflects what the server actually returns per video.
> Rapid quality switching on the same video may trigger server-side downgrade — the app shows an explicit "server downgraded" message when that happens.

## Build

Deliberately pinned to the 2013–2014 toolchain:

| Component | Version |
|---|---|
| Android Gradle Plugin | 2.3.2 |
| Gradle | 3.3 |
| JDK | 7 (compile) / 8 (Gradle JVM) |
| compileSdk / buildTools | 23 / 25.0.3 |

```bash
gradlew.bat assembleRelease
# output: app/build/outputs/apk/app-release.apk
```

Signing is read from `local.properties` (**git-ignored, never commit it**):

```properties
KEY_PATH=/absolute/path/to/your.jks
KEY_PASSWORD=******
ALIAS_NAME=your_alias
ALIAS_PASSWORD=******
```

### Native libraries (optional)

All five ABIs of `libijkffmpeg.so` / `libijkplayer.so` / `libijksdl.so` are **compiled from source by this project**:

- IJKPlayer (`ff4.0--ijk0.8.8--20210426--001`)
- FFmpeg 4.0 (`--disable-gpl`, LGPL-2.1+)
- OpenSSL 1.0.2u (statically linked, for HTTPS)
- SoundTouch `ijk-r0.1.2-dev` (playback speed)
- libyuv `ijk-r0.2.1-dev`
- NDK r14b (API 9 ABIs) and r16b (arm64-v8a / x86_64)

See [docs/BUILD_NATIVE.md](docs/BUILD_NATIVE.md) for the full recipe and pitfalls.
