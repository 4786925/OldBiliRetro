OldBiliRetro 兼容性列表

最后更新：2026-10  |  适用版本：1.0.0 beta 及以后

本页说明本应用在各 CPU 架构、各 Android 版本上的可用性，以及播放器与清晰度的支持情况。 若你的设备不在下表范围内，仍可尝试安装，但无法保证视频解码正常。

项目数值

二、CPU 架构兼容性

应用内置 5 套独立编译的原生播放器（IJKPlayer + FFmpeg 4.0 + OpenSSL 1.0.2u + SoundTouch + libyuv）， 全部由项目自行编译，无第三方二进制。

ABI 架构最低 API对应 Android原生播放器HTTPS 播放说明
armeabi（ARMv5）92.3 ~ 2.3.7自编译支持最老设备，ARMv5/ARMv6 机器
armeabi-v7a（ARMv7）92.3 ~ 4.4自编译支持2011~2014 年主流手机
arm64-v8a（ARM64）215.0 ~ 17自编译支持2015 年后的主流手机
x86（32 位）92.3 ~ 7.x自编译支持Intel 平板 / 模拟器
x86_64（64 位）215.0 以上自编译支持64 位模拟器 / Chromebook

注：ARM64 与 x86_64 的 API 下限由架构本身决定（Google 从未提供更低 API 的 64 位 NDK 平台）。

四、清晰度兼容性

清晰度可用性条件 / 说明
360P全平台可用单流，任何架构均可播放
480P已下架B 站服务端已不再提供 32 档，选择后会被自动降到 360P
720P全平台可用单流
1080P大多数视频可用单流；部分内容需要登录或大会员
1080P 60 帧部分视频需 DASH 模式；Android 2.x 隐藏此档
2K少数视频需 DASH 模式 + 大会员；Android 2.x 隐藏此档
清晰度列表是动态的：应用会按服务端实际返回的可选档位显示， 所以不同视频看到的档位可能不同（例如只有 360P/720P）。

六、已知限制

现象原因
没有 480P 选项B 站已下架 32 档，所有设备（含官方 App）同样没有
Android 2.x 看不到 1080P60 / 2K老系统不支持 DASH 音画分离所需的播放能力，应用主动隐藏
部分网络下无法播放B 站 CDN 对出口 IP 做风控（HTTP 403），与设备无关，换网络即可
2.3 打开内嵌网页较慢系统 WebView 版本过旧，属正常现象

七、推荐测试顺序

1. 先播一个普通视频，确认能出画面、有声音；
2. 打开清晰度菜单，确认列表与本文档一致；
3. 发送一条弹幕，确认能上屏；
4. 长按画面，确认切换到 2 倍速；
5. 进设置 → 兼容性列表，对照本页检查设备信息。
