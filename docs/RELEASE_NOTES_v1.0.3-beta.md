## ⚠️ 已知问题（欢迎在 Issue 反馈）

### 1. 按键手机适配**尚未完成**

目前只做了最基础的三件事：

- `↑ / ↓` 在列表中移动选中项
- `确认键` 打开选中项
- `数字键 1~9` 直接打开列表第 N 项

**仍然存在的问题**：

- 顶部搜索框、`推荐 / 热门 / 番剧 / 影视 / 直播` 这些标签**无法用方向键选中**
- 底部 `首页 / 动态 / 消息 / 我的` 会被方向键优先抢走焦点
- 部分按钮（刷新、选择目录等）仍然需要触摸操作

之前尝试过「焦点环 + 长按返回软键菜单」的方案，但因为问题更多已经回滚。
**这一版先保持最基础可用，等大家实机反馈后再决定下一步方案。**

如果你使用按键手机（如 SH-02L、京瓷、富士通等日系机型），欢迎反馈：

- 机型、Android 版本
- 哪些按键可用 / 哪些完全没反应
- 期望的操作方式（例如：数字键选标签？长按返回出菜单？）

### 2. 字体切换速度慢

- 切换字体时会**结束进程并重启 APP**，重启过程约 1~3 秒（老设备更久）
- 重启后首页与设置页能立即显示新字体，但个别页面（部分详情页、弹窗）可能需要滑动一下才完全刷新
- 字体文件为 GB2312 子集（约 3.5MB），首次加载有轻微延迟
- 后续版本会尝试「不重启进程、仅重建界面」的快速切换方式

### 按键手机使用说明（当前版本）

| 按键 | 作用 |
|---|---|
| ↑ / ↓ | 列表内上下移动选中项 |
| 确认键（中心键 / Enter） | 打开选中项 |
| 1~9 | 直接打开列表第 1~9 项 |
| 返回键 | 返回上一页 |

播放器内：确认键 = 显示/隐藏控制栏，`← / →` = 快退/快进 10 秒，`*` = 弹幕开关。

顶部标签、搜索框、刷新等功能**暂时仍需触摸**，或使用支持触摸的机型。
