## OldBiliRetro 1.0.4 beta

> **不要安装旧版本，新版本会越来越完善。**

### 更新内容

1. **暂时移除「界面字体」切换**
   - 设置里的「界面字体」选项与内置楷体字体（3.5MB）已移除，APK 减小到 **14.5MB**
   - 相关代码仍保留（预留），大家普遍不缺中文字体，等有人确实需要时再加回来
   - 顺带修掉了「切换字体后进设置闪退」的问题（该功能已下线，崩溃路径一并消失）
2. **所有设置都会完整保留**
   - 去掉上一版的一次性清理逻辑，除字体外不会动任何设置
3. **搜索大幅优化**
   - **每类结果独立缓存**：切换 视频 / 番剧 / 影视 / 直播 / 用户 时立即显示已有结果，不再清空、不再重复请求
   - **412 风控自动重试**：遇到 B 站限流（412 / -352）自动刷新 buvid 并重试（最多 3 次，退避 0.7→1.4 秒）
   - **空结果自动重试**：首次返回空时自动再试，减少「搜不到、要反复切换」的情况
   - **加载中提示**：所有列表都会显示「加载中…」
   - **下拉刷新**：搜索页支持下拉重新搜索
   - **上滑加载更多**：保留分页加载
   - 失败时显示错误信息与「重试」按钮，不再无限转圈
4. **个人主页 / 动态 的 412 也走同一条重试链路**，并加了加载中提示
5. 其余为 1.0.3 已有内容：新图标（泉此方）、空间分享、个人主页两行排版、B 站链接外部打开、详情页简介位置、合集折叠与合集列表、关于页滚动居中 + 图标作者、首页加载更多不再跳顶、默认清晰度移除 480P、官网域名、联系方式更新

## ⚠️ 已知问题（欢迎在 Issue 反馈）

### 1. 按键手机适配**尚未完成**

目前只有：

- `↑ / ↓` 在列表中移动选中项
- `确认键` 打开选中项
- `数字键 1~9` 直接打开列表第 N 项

**仍然存在的问题**：

- 顶部搜索框、`推荐 / 热门 / 番剧 / 影视 / 直播` 标签**无法用方向键选中**
- 底部 `首页 / 动态 / 消息 / 我的` 会被方向键优先抢走焦点
- 刷新、选择目录等按钮仍需触摸

之前尝试的「焦点环 + 长按返回软键菜单」方案问题更多，已回滚。
**这一版先保持最基础可用，等大家实机反馈后再决定下一步方案。**

欢迎反馈：机型、Android 版本、哪些键可用/没反应、期望的操作方式。

### 2. 字体切换功能已暂时移除

- 本版设置里没有「界面字体」
- 如果你确实需要内置中文字体（例如老设备缺少中文字体），请在 Issue 里说明机型与现象，会考虑加回
- 后续加回时会采用「不重启进程」的快速切换方式

### 3. B 站风控

搜索、空间、动态等接口在访问过于频繁时会被 B 站限流（412）。
本版已加入自动重试与缓存，但极端情况下仍可能失败，失败时会出现「重试」按钮。
