# OldBiliRetro 1.0.6 beta 更新日志

> 1.0.5 之后的全部修复；老设备建议使用 armv7 精简包（约 3MB）。

### 更新内容

- 修复安卓 2.3 / 4.0 / 4.1 点「查看回复」立即闪退（旧系统没有 Builder.setOnDismissListener）
- 修复消息页翻页时一直显示「加载中」
- 私信里的分享卡片（JSON）显示成标题 + UP 主，点击直接打开对应视频
- 私信文字里的链接可点，弹出「应用内浏览器 / 系统浏览器 / 复制链接」
- 私信与消息支持长按复制
- 会话列表预览不再显示 JSON，改为「[视频] 标题」
- 修复老浏览器下载得到 555B 错误页、安装提示解析失败（下载令牌不再依赖 Cookie）
- **修复动态（图文动态）评论区打不开、报 -400 invalid oid**
- **首次登录消息列表加载极慢：改为批量补昵称头像，上百次请求降到 2 次**
- **点桌面图标不再停在上次的消息页，固定回到首页**
- **通知检查间隔改为 5 分钟，可在设置里调 5/10/15/30**
- **通知支持消息预览（私信显示对方昵称与内容，回复显示回复内容）**
- **私信未读现在也会触发通知**
- 修复 GitHub 发布说明中文乱码（改用 UTF-8 直接提交）

### 已知问题

- 消息部分还不够稳定：从消息点进评论可能失败，或加载较慢，后续版本继续完善
- 通知推送仍有一定延迟（受系统省电策略影响），1.0.7 会继续优化
