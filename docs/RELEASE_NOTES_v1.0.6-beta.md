# OldBiliRetro 1.0.6 beta 更新日志

> 主要修复老安卓崩溃、消息卡片显示、链接打开与复制。

### 更新内容

- 修复安卓 2.3 / 4.0 / 4.1 点「查看回复」立即闪退的问题（旧系统不存在 Builder.setOnDismissListener）
- 修复消息页翻页时可能一直显示「加载中」的问题
- 私信里的分享卡片（原来的 JSON 文本）现在显示成标题 + UP 主，点击直接打开对应视频
- 私信文字里的网页链接可点击，弹出「应用内浏览器 / 系统浏览器 / 复制链接」选择
- 所有私信和消息预览支持长按复制
- 会话列表的预览不再显示 JSON，改为「[视频] 标题」
- 下载链接改为不依赖 Cookie 的签名令牌，修复老浏览器下载得到 555B 错误页、安装提示解析失败
- 修复 GitHub 发布说明中文乱码（改用 UTF-8 直接提交）

### 已知问题

- 消息部分还不够稳定：从消息点进评论可能失败，或加载较慢，后续版本继续完善
- 通知推送比较慢、Bug 较多：后台检查间隔 15 分钟，实时性有限，点击跳转偶尔不准，等待下一步完善
