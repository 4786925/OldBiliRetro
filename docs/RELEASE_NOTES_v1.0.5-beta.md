# OldBiliRetro 1.0.5 beta 更新日志

> 1.0.4 beta 之后的全部改动。老设备建议使用 armv7 精简包（约 3MB）。

### 更新内容

- 消息页顶部新增「私信 / 回复 / @我」三个标签，与官方一致
- 互动消息显示对方回复的具体内容（原来只显示视频标题）
- 修复消息时间全部显示 1970-01-01 的问题
- 修复三个标签内容互相串、切回私信要等好几秒的问题
- 修复消息加载更多时列表跳回顶部
- 修复翻页到末尾时内容循环重复的问题
- 点击回复/@我 直接进入评论区，定位到那条评论并黄色闪两下
- 楼中楼里的回复会自动展开并定位到具体那条
- 新增消息通知：后台每 15 分钟检查一次，打开应用时也会立刻检查
- 通知栏提示「你有 N 条新消息」，并列出互动 / 关注更新 / 推荐 / 订阅条数
- 点击通知按类型直达：回复/@我 → 对应评论并高亮；私信 → 对应聊天；点赞 → 被赞的视频或动态
- 设置页新增「推送通知」分类：总开关、互动通知、关注通知、内容推荐、订阅预约通知、其他通知、通知权限
- 通知支持安卓 13+ 权限申请，安卓 2.x 走旧版通知接口
- 未读数没变化且 30 分钟内提醒过则不重复打扰
- 评论昵称后显示等级 LV0 ~ LV6+（蓝色，官方样式）
- 评论区滑到底不再立刻 412：请求间隔 900ms，被限流时暂停并显示「被B站限流，点击继续加载」
- 修复「屏幕方向」设置无效的问题
- 主页列表支持左右滑动切换 推荐 / 热门 / 番剧 / 影视 / 直播
- 设置底部新增「法律信息」，列明相关法律法规与免责声明
- 提供全架构包与 V7 精简包两种安装包

## 已知问题

- 消息部分还不够稳定：从消息点进评论可能失败，或加载较慢，后续版本继续完善
- 通知推送比较慢、Bug 较多：后台检查间隔 15 分钟，实时性有限，点击跳转偶尔不准，等待下一步完善
