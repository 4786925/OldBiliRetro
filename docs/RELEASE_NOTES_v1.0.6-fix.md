# OldBiliRetro 1.0.6 fix 更新日志

> 1.0.6 之后的集中修复版；版本号仍保持 1.0.6，内置 IJK 播放器仍在移植中。

### 更新内容

- 动态页：超过 5 分钟自动刷新；刷新时替换旧缓存并按动态 ID 去重，不再一直显示十几天前的动态
- 退出登录：清空头像、昵称、名片缓存与消息/动态缓存；未登录时点「我的」头像不会进入个人主页
- 下载：公共下载目录不可写时自动回退到应用私有目录，并自动创建父目录；安卓 2.x 下载优先使用 HTTP 直链、下载连接复用 TLS 兼容层，修复老设备无法下载
- 弹幕：修复低端机（Android 2.x）弹幕全部挤在顶部；关闭后重新打开弹幕会立即按当前播放进度恢复；暂停恢复改用 resume，不再闪一下或丢失弹幕；暂停时保留冻结画面
- 弹幕设置：从播放器进入固定横屏，从「我的 → 设置」进入固定竖屏
- 安卓 2.1/2.2 兼容：扫码登录改用内置 Swetake 二维码库（可正常生成二维码并登录）、强制 IPv4 解析、SharedPreferences 使用 commit、ActivityLifecycle 回调增加版本保护
- 通知：检查间隔改为 5 分钟（可调 5/10/15/30），通知中显示私信/回复预览，私信未读也计入提醒

### 已知问题

- Android 2.3 以下的内置 IJK 播放器仍在移植中（系统缺少 libOpenSLES 与 libandroid/ANativeWindow），暂时不能内置播放；2.3 及以上正常
- 部分老设备仍可能受系统省电策略影响，通知有延迟
