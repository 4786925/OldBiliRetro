## OldBiliRetro 1.0.2 beta（下载管理增强）

> **不要安装旧版本，新版本会越来越完善。**

### 新增

- **下载列表多选**：顶部「多选」按钮进入多选模式，点条目即可勾选/取消，右上角显示「已选 N 项」，支持「全选」
- **批量开始**：一键继续所选任务（暂停 / 失败 / 等待中）
- **批量删除（二次确认）**：
  1. 第一次确认：弹出「确定要删除选中的 N 个下载任务吗？」
  2. 第二次选择：**仅删除记录（保留文件）** 或 **删除记录和文件**
- **未完成下载也可删除**：下载中、已暂停、失败、等待中的任务都能删（会自动中断下载并清理 `.part`）
- **打开文件位置**：
  - 每条任务长按 →「打开文件位置」，显示完整路径，可一键复制
  - 已完成任务的条目按钮直接变成「打开位置」
  - 底部「打开下载文件夹」同样支持（新系统因 `file://` 限制会给出可复制路径）
- **更新提示固定文案**：设置 → 检查更新 的提示里都会带上「不要安装旧版本，新版本会越来越完善。」

### 修复 / 变更

- 下载列表条目按钮：已完成时显示「打开位置」，替代原来的「删除」（删除改到长按菜单，避免误触）
- 批量删除时自动停止正在下载的任务并清理残留文件

### 安装包

- `OldBiliRetro-1.0.2-beta.apk`（14.5 MB，已签名）
- `versionCode 3` / `versionName 1.0.2 beta`
- 覆盖安装即可（签名不变）
